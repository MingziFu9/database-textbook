## 教学说明

**学习目标**

1. 能说出内连接、左外连接、右外连接、全外连接结果的区别（理解）；
2. 能根据需求选择连接方式，例如用左连接找“从没下过单的顾客”（应用）。

**画面与操作**

- 上方切换连接方式；左右两张源表中，蓝色是对上的行，黄色是没对上但被保留的行，划掉的是被丢掉的行；
- 下方显示 SQL 和结果表，NULL 用灰色斜体标出；“忘写连接条件”展示 4 × 5 = 20 行的笛卡尔积。

**数据来源**：与实验 5-1 的 joindemo 库相同（4 位顾客、5 笔订单），结果与 MySQL 8.4 实际运行一致。

**课堂用法建议**

1. 先让学生在纸上写出内连接的结果，再切换验证；
2. 切到左连接后问：“怎样只留下没买过东西的顾客？”引出 `WHERE o.order_id IS NULL`。
