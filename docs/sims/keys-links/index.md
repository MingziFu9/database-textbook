## 教学说明

**学习目标**

1. 能指出订单表中的外键分别引用哪张表的主键（理解）；
2. 能解释参照完整性：外键的值要么为空，要么必须在被参照表中存在（理解、应用）。

**画面与操作**

- 左边是订单表和订单明细，右边是顾客、员工、商品三张表的节选；点任意一行订单，引用到的行变蓝；
- 下方可以执行 UPDATE 改顾客编号，或改成 NULL，或尝试删除被引用的顾客，显示 MySQL 的真实报错。

**数据来源**：示例库 shop 中订单 2496—2501 及相关的顾客、员工、商品；报错信息为编者在 MySQL 8.4 上实际执行的输出。

**课堂用法建议**

1. 先点订单 2499（散客），问学生“为什么顾客那里是空的”；
2. 让学生预测“改成 999”“删除顾客 3”会不会成功，再点按钮验证，引出 ERROR 1452 和 1451 的区别。
