## 教学说明

**学习目标**

1. 能在表中找出部分依赖和传递依赖（分析）；
2. 能按“把依赖的列和决定因素拿出去单独成表”的方法拆到第三范式（应用）。

**画面与操作**

- 五步：大表 → 找部分依赖 → 拆到 2NF → 找传递依赖 → 拆到 3NF；
- 列的颜色表示它由谁决定，红色数字表示重复存储的值；表名后括号里是完整数据的行数。

**数据来源**：实验 7-2 的 normdemo.order_wide（174 行）前 8 行；拆分后各表行数 82、45、174、13 为 MySQL 实测。

**课堂用法建议**

1. 第 0 步让学生先数一数“高轩轩的电话存了几遍”；
2. 第 1 步之前，让学生自己写出函数依赖，再对照屏幕。
