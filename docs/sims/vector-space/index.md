## 教学说明

**学习目标**

1. 能说出“意思相近 = 向量相近”的基本思想（理解）；
2. 能区分余弦相似度（看方向）和欧氏距离（看直线距离）（理解）。

**画面与操作**

- 蓝色是早餐类，橙色是零食类，棕色是日用品；红点是查询，可以拖动；
- 绿色虚线连着当前最近的 3 个词；右侧表格按所选的度量排序，同时列出两种数值；
- “早餐（缩短一半）”把查询向量的每个数都除以 2，方向不变、长度变短。

**数据来源**：13 个词的二维坐标由编者手工设定，只为教学；真实的嵌入向量有几百维，由嵌入模型算出（见实验 12-2）。

**课堂用法建议**

1. 先点三个预设查询，让学生说出最近的 3 个词为什么合理；
2. 点“早餐（缩短一半）”，切换两种度量，观察哪个排名变了，引出“文本向量常用余弦相似度”；
3. 把查询拖到两类之间，讨论“边界上的问题”为什么难判断。
