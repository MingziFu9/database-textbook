# 交互动画

这些动画都是普通网页，不需要安装任何软件，也不需要联网调用接口，在电脑和手机浏览器上都能打开。每个动画都嵌在对应章节的正文里，也可以从这里单独打开，适合课堂演示。

<!-- sims:start -->
| 章 | 动画 | 你可以做什么 |
|---|---|---|
| 第 1 章 | [数据库家族](db-family/index.md) | 给 8 个业务场景各选一种合适的数据库类型（关系型、键值、文档、列族、图、向量），马上看到对错和理由 |
| 第 2 章 | [主键与外键](keys-links/index.md) | 点一行订单，看它通过外键连到哪位顾客、哪位收银员、买了哪些商品；把外键改成不存在的编号，看参照完整性怎样报错 |
| 第 2 章 | [关系代数五种运算](relational-algebra/index.md) | 选择、投影、连接、并、差五种运算，选一种、改条件，看两张小表怎样变成结果表，并对照 SQL 写法 |
| 第 4 章 | [分组统计与 HAVING](group-having/index.md) | 选分组的列和聚合函数，看 48 种商品怎样落进“篮子”、每个篮子怎样变成一行；打开 HAVING 拖动门槛，看哪些组被拿走 |
| 第 4 章 | [SELECT 的执行顺序](sql-order/index.md) | 一步步播放一条带 WHERE、GROUP BY、HAVING、ORDER BY、LIMIT 的查询，看每一步之后中间表的样子，理解为什么 WHERE 里不能用聚合函数和别名 |
| 第 5 章 | [四种连接对比](join-types/index.md) | 切换内连接、左连接、右连接、全连接，看两张小表里哪些行连上、哪些行被保留并填上 NULL、哪些行被丢掉；也可以看看忘写连接条件的后果 |
| 第 6 章 | [E-R 图转换成表](er-to-table/index.md) | 选一对一、一对多、多对多三种联系，看陈氏 E-R 图怎样一步步变成表：外键加在哪一边，什么时候要多建一张中间表 |
| 第 7 章 | [从大表到第三范式](normal-forms/index.md) | 一步步找出订单大表中的部分依赖和传递依赖，拆到第二范式、第三范式，看每一步消除了哪些重复 |
| 第 8 章 | [B+ 树查找](bplus-tree/index.md) | 输入一个顾客编号，看查找怎样从根节点一层层走到叶子；再做范围查找，看它怎样顺着叶子链表往后读 |
| 第 9 章 | [隔离级别与并发问题](isolation-levels/index.md) | 两个会话按时间顺序操作同一种商品，切换四种隔离级别，看脏读、不可重复读、幻读什么时候出现 |
| 第 11 章 | [SQL 注入演示](sql-injection/index.md) | 在会员登录框里输入手机号或注入串，对比拼接写法和参数化写法生成的 SQL 与查询结果 |
| 第 12 章 | [词语向量空间](vector-space/index.md) | 平面上的点是词的二维向量，拖动查询点，实时比较余弦相似度和欧氏距离，看最近的 3 个词 |
| 第 12 章 | [HNSW 分层搜索](hnsw-search/index.md) | 在三层邻居图上播放一次近似最近邻搜索，调节候选数 ef_search，看比较次数和是否找到真正的最近邻 |
| 第 12 章 | [RAG 检索流程](rag-flow/index.md) | 选一个顾客问题，逐步播放切块、向量化、检索的过程，看检索出的前 3 段资料和最终拼成的提示词 |
