## 教学说明

**学习目标**

1. 能说出 B+ 树“根 → 中间节点 → 叶子”的查找过程（理解）；
2. 能解释为什么有索引时只读几个节点，而全表扫描要看所有行（理解）；
3. 能说明范围查找为什么要靠叶子之间的链表（理解）。

**画面与操作**

- 输入一个编号点“查找”：根节点和中间节点里黄色的是本次比较的分界值，蓝色框是走过的路，绿色是到达的叶子；
- 输入一个范围点“范围查找”：先找到起点所在的叶子，再顺着链表往右读；
- 右下角对比 B+ 树读的节点数和全表扫描要看的行数。

**数据来源**：示例库 shop 的 customer 表有 200 位顾客，编号 1～200。树的形状是为了教学画的（每个节点只放 3 个分界值），真实的 InnoDB 一个节点是 16 KB 的页，能放几百个分界值。

**课堂用法建议**

1. 先让学生猜：找 137 号顾客要读几个节点？再点“查找”验证；
2. 换几个编号（1、50、51、200），观察每次都是 3 步；
3. 做范围查找 45～70，让学生数一数读了几个叶子，再对照实验 8-2 里 `EXPLAIN` 的 `type = range`。
