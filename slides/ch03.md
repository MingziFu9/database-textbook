# 3.1 认识 SQL

## SQL 的特点
- **声明式**：说“要什么”，不说“怎么做”
- **一种语言管全部**：建表、增删改查、权限
- 关键字**接近英语**
- 各数据库通用，细节略有差别

## 四类 SQL 语句
| 类别 | 管什么 | 主要语句 |
|---|---|---|
| **DDL** | 结构 | CREATE、ALTER、DROP、TRUNCATE |
| **DML** | 数据 | INSERT、UPDATE、DELETE |
| **DQL** | 查询 | SELECT |
| **DCL** | 权限 | GRANT、REVOKE |

## 书写规则
- 语句以英文分号 `;` 结尾
- 关键字不分大小写，本书**大写**
- 库名、表名、列名用**英文小写**
- 字符串、日期用**单引号**
- 注释：`-- 单行`、`/* 多行 */`
- 标点**全用英文半角**

::: notes
初学者最常见的错误是中文逗号、中文括号和中文引号，报 1064 语法错误时先查这个。
:::

# 3.2 建数据库

## CREATE DATABASE
```sql
CREATE DATABASE myshop
  DEFAULT CHARACTER SET utf8mb4;
SHOW DATABASES;
USE myshop;
DROP DATABASE myshop;   -- 不能撤销！
```
- 字符集用 **utf8mb4**，中文和表情都能存
- 系统库（mysql、sys……）**不要去改**

# 3.3 数据类型

## 数值类型
| 类型 | 能存什么 | 小店里用在哪 |
|---|---|---|
| `INT` | 整数，约 ±21 亿 | 编号、库存、数量 |
| `SMALLINT` | 小整数 | 出生年份 |
| `DECIMAL(8,2)` | 精确小数 | 售价、进价、工资 |
| `FLOAT` / `DOUBLE` | 近似小数 | 传感器读数、向量 |

::: notes
存钱一定用 DECIMAL。演示 0.1 + 0.2 用浮点数会得到 0.30000000000000004；FLOAT 存 1234567.89 会变成 1234570。
:::

## 字符串与日期
| 类型 | 适合 |
|---|---|
| `CHAR(11)` | 手机号、身份证号（定长） |
| `VARCHAR(40)` | 姓名、商品名（变长） |
| `TEXT` | 商品详情、评论 |
| `ENUM('男','女')` | 只有几个固定值 |
| `DATE` / `DATETIME` | 日期 / 下单时间 |

::: notes
VARCHAR(n) 的 n 是字符数，不是字节数；“燕麦片”三个字占 9 字节。手机号不参与计算，存成字符串。
:::

## 选类型的口诀
- 能用整数不用小数，能用短的不用长的
- **钱用 DECIMAL**，编号类数字用 CHAR
- 长度固定 CHAR，不固定 VARCHAR
- 日期时间用**日期类型**
- 取值只有几种：ENUM 或另建一张表

# 3.4 建表与约束

## CREATE TABLE
```sql
CREATE TABLE product (
  product_id  INT PRIMARY KEY AUTO_INCREMENT,
  name        VARCHAR(40) NOT NULL,
  category_id INT NOT NULL,
  price       DECIMAL(8,2) NOT NULL CHECK (price > 0),
  stock       INT NOT NULL DEFAULT 0,
  shelf_date  DATE,
  FOREIGN KEY (category_id) REFERENCES category(category_id)
);
```

## 六种常用约束
| 约束 | 关键字 | 作用 |
|---|---|---|
| 主键 | `PRIMARY KEY` | 不重复、不为空 |
| 外键 | `FOREIGN KEY … REFERENCES` | 值必须在被参照表中 |
| 非空 | `NOT NULL` | 必须填 |
| 唯一 | `UNIQUE` | 不重复，可为空 |
| 默认值 | `DEFAULT` | 不填时自动填 |
| 检查 | `CHECK (条件)` | 满足条件 |

::: notes
主键和唯一约束的区别：一张表只有一个主键且不能为空；唯一约束可以有多个，可以为空。列级约束写在列后面，涉及多列的约束（如复合主键）只能写成表级的。
:::

## 外键的参照动作
| 写法 | 删除被参照的行时 |
|---|---|
| 不写 / `RESTRICT` | 拒绝，报错 1451 |
| `ON DELETE CASCADE` | 引用它的行一起删 |
| `ON DELETE SET NULL` | 外键改成 NULL |

- 建表顺序：**先建被参照的表**，再建参照它的表

# 3.5 修改和删除表

## ALTER TABLE
| 想做什么 | 写法 |
|---|---|
| 增加列 | `ADD COLUMN 列名 类型` |
| 改类型 | `MODIFY COLUMN 列名 新类型` |
| 改列名 | `RENAME COLUMN 旧名 TO 新名` |
| 删除列 | `DROP COLUMN 列名` |
| 改表名 | `RENAME TABLE 旧名 TO 新名` |

## DROP、TRUNCATE、DELETE
| 语句 | 删什么 | 表还在吗 | 自增编号 |
|---|---|---|---|
| `DROP TABLE` | 结构和数据 | 不在了 | —— |
| `TRUNCATE TABLE` | 全部数据 | 空表 | 从 1 重来 |
| `DELETE FROM` | 数据（逐行） | 空表 | 接着编 |

# 3.6 插入、修改、删除数据

## INSERT / UPDATE / DELETE
```sql
INSERT INTO product (name, category_id, price)
VALUES ('燕麦片 1kg', 2, 26.90);

UPDATE product SET stock = 50 WHERE product_id = 2;

DELETE FROM product WHERE product_id = 3;
```
- INSERT **总是写出列名**

## “忘写 WHERE”的事故
- 没有 WHERE = 改 / 删**全部行**
- **先查后改**：先 SELECT 看影响哪几行
- 打开安全更新模式 `SET SQL_SAFE_UPDATES = 1;`
- 改之前先备份，或在事务里改

# 3.7 从文件导入数据

## 从 CSV 批量导入
- 做法一：DBeaver **导入向导**（推荐初学者）
- 做法二：`LOAD DATA LOCAL INFILE`
- 先导入**被参照的表**，再导入参照它的表
- 文件编码用 UTF-8

## 前沿视窗：让大模型写建表语句
| 检查项 | 常见问题 |
|---|---|
| 主键有没有？ | 漏掉或选错列 |
| 钱是不是 DECIMAL？ | 常写成 FLOAT |
| 外键的表存在吗？ | 会“编”一个表名 |
| 字符集 utf8mb4？ | 照搬老资料的 utf8 |
| 是不是 MySQL 语法？ | 混入 SERIAL、IDENTITY |
