# 1.1 什么是数据库

## 数据、信息与数据库
- **数据**：记录下来的符号（燕麦片、26.90）
- **信息**：加工后对人有用的含义
- **数据库**：长期存储、有组织、可共享的数据集合
  - 长期存储：关机不丢
  - 有组织：按结构存放
  - 可共享：多个程序同时用一份

## DBMS 做什么
| DBMS 的功能 | 通俗地说 | 小店里的例子 |
|---|---|---|
| 数据定义 | 规定数据长什么样 | 价格必须大于 0 |
| 数据操作 | 增、删、改、查 | 查库存少于 10 的商品 |
| 运行管理 | 多人同用不打架 | 两台收银机抢最后一袋米 |
| 安全与权限 | 谁能看、谁能改 | 店员看不到会员手机号 |
| 建立与维护 | 导入、备份、恢复 | 每晚自动备份 |

::: notes
数据库里的数据交给专门的软件管理，这个软件就是数据库管理系统（DBMS），MySQL、PostgreSQL 都是。
:::

## 数据库系统
!mermaid 1
- 用户 → 应用程序 → **DBMS** → 数据库
- 再加上管理员、硬件和操作系统
- 合起来叫**数据库系统**

## 数据库比 Excel 强在哪里
| 小店的问题 | 数据库怎么解决 |
|---|---|
| 两份商品表对不上 | 只存一份，**数据共享、冗余小** |
| 汇总要一下午 | 一条 SQL，**高效查询** |
| 两人录入互相覆盖 | 管理**并发访问** |
| 蓝屏丢数据 | 日志 + 备份，可以**恢复** |
| 员工拷走顾客表 | 按用户分配**权限** |

::: notes
还有一点 Excel 做不到：数据一致性约束。在数据库里可以规定“价格必须大于 0”“订单里的顾客必须存在”，录错了数据库直接拒绝。
:::

# 1.2 数据管理的发展

## 三个阶段
| 阶段 | 数据存在哪里 | 主要问题 |
|---|---|---|
| 人工管理 | 卡片、纸带 | 不保存，不能共享 |
| 文件系统 | 硬盘上的文件 | 冗余大，格式变了程序要改 |
| 数据库系统 | 由 DBMS 统一管理 | —— |

::: notes
小店现在的做法就是文件系统阶段。1970 年科德提出关系模型，70 年代后期 SQL 诞生，90 年代出现 MySQL、PostgreSQL，2000 年后 NoSQL 兴起，近几年大模型带火了向量数据库。
:::

## 三级模式与数据独立性
!mermaid 2
- **外模式**：某类用户看到的数据
- **模式**：全部表和列的逻辑结构
- **内模式**：硬盘上怎么存
- 一句话：**换了存法，查法不变**

# 1.3 数据库家族

## 关系型数据库
- 数据存成**二维表**，表之间用编号联系
- 用 **SQL** 定义和操作数据
- 代表：**MySQL**（本课主线）、PostgreSQL、Oracle、SQL Server、SQLite
- 网页“试一试”用的就是 SQLite

## NoSQL 数据库
| 类型 | 代表产品 | 适合的场景 |
|---|---|---|
| 键值 | Redis | 缓存、购物车、排行榜 |
| 文档 | MongoDB | 商品详情、内容管理 |
| 列族 | HBase | 海量日志、物联网 |
| 图 | Neo4j | 社交关系、知识图谱 |

::: notes
NoSQL 不是取代关系型数据库，而是补短处。订单、账务放 MySQL，浏览记录放 Redis，商品详情放 MongoDB，常常一起用。
:::

# 1.4 国产数据库

## 常见的国产数据库
| 产品 | 兼容哪种语法 |
|---|---|
| 达梦（DM） | 兼容 Oracle 为主 |
| 人大金仓 | 兼容 PostgreSQL、Oracle |
| openGauss | 基于 PostgreSQL |
| OceanBase | 兼容 MySQL、Oracle |
| TiDB | 兼容 MySQL |

::: notes
数据库和操作系统、芯片一样是信息系统的地基。随着信创推进，政府、金融、能源、电信在逐步换用国产数据库。大多数国产数据库兼容 MySQL 或 PostgreSQL 语法，学好本课的 SQL 就能很快上手。
:::

# 1.5 数据库与人工智能

## AI 离不开数据库
!mermaid 3
- **训练数据**从数据库里来
- 模型**结果存回**数据库
- 大模型需要**向量数据库**
