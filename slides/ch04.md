# 4.1 SELECT 的基本用法

## 选择列、别名、计算列
```sql
SELECT name AS 商品名, price AS 售价,
       price - cost AS 每件毛利,
       ROUND((price - cost) / price * 100, 1) AS 毛利率
FROM product;
```
- `SELECT *`：所有列（练习可以，程序里少用）
- `AS` 起别名，计算列也能起名
- `DISTINCT` 去掉重复行

# 4.2 WHERE：筛选行

## 比较运算
| 运算符 | 含义 | 例子 |
|---|---|---|
| `=` | 等于 | `category_id = 4` |
| `<>` 或 `!=` | 不等于 | `status <> '已退款'` |
| `>`、`>=` | 大于、大于等于 | `price >= 50` |
| `<`、`<=` | 小于、小于等于 | `stock < 20` |

## BETWEEN、IN、LIKE
- `price BETWEEN 10 AND 20`：**含两端**
- `category_id IN (4, 5)`：在列表中
- `name LIKE '%奶%'`：模糊匹配
  - `%` 任意多个字符，`_` 恰好一个
- `phone IS NULL`：找空值，**不能写 = NULL**

## AND、OR、NOT 与括号
```sql
SELECT name, category_id, price
FROM product
WHERE (category_id = 4 OR category_id = 5)
  AND price > 10;
```
- AND 比 OR **先算**
- 混用时**一定加括号**

# 4.3 排序与分页

## ORDER BY 与 LIMIT
```sql
SELECT name, price FROM product
ORDER BY price DESC     -- 从高到低
LIMIT 5;                -- 只要前 5 行

LIMIT 10, 10            -- 跳过 10 行，取 10 行（第 2 页）
```
- 默认升序 `ASC`，降序 `DESC`
- 多列排序：先按第一列，相同再按第二列

# 4.4 常用函数

## 字符串与数值函数
| 函数 | 例子 | 结果 |
|---|---|---|
| `CONCAT` | `CONCAT('花生油', '（桶）')` | 花生油（桶） |
| `LEFT` | `LEFT('东北大米', 2)` | 东北 |
| `REPLACE` | `REPLACE('5kg', 'kg', '千克')` | 5千克 |
| `ROUND` | `ROUND(26.875, 2)` | 26.88 |
| `MOD` | `MOD(17, 5)` | 2 |

::: notes
手机号脱敏：CONCAT(LEFT(phone, 3), '****', RIGHT(phone, 4))，徐洋娟的 10054751779 显示为 100****1779，第 10 章数据脱敏还会用到。
:::

## 日期函数
| 函数 | 例子 | 结果 |
|---|---|---|
| `YEAR`、`MONTH` | `MONTH('2025-01-01 09:32')` | 1 |
| `DATE_FORMAT` | `DATE_FORMAT(d, '%Y-%m')` | 2025-01 |
| `DATEDIFF` | `DATEDIFF('2026-06-30', '2026-06-01')` | 29 |
| `DATE_SUB` | `DATE_SUB('2026-06-30', INTERVAL 3 MONTH)` | 2026-03-30 |

## 条件函数：CASE
```sql
SELECT name, stock,
  CASE WHEN stock = 0  THEN '缺货'
       WHEN stock < 10 THEN '库存紧张'
       ELSE '充足' END AS 库存状态
FROM product;
```
- 简单二选一用 `IF(条件, 真值, 假值)`
- `IFNULL(x, 替代值)` 处理空值

# 4.5 聚合与分组

## 聚合函数
| 函数 | 作用 | 对 NULL |
|---|---|---|
| `COUNT(*)` | 行数 | 都算 |
| `COUNT(列)` | 非空的行数 | 跳过 |
| `SUM`、`AVG` | 求和、平均 | 跳过 |
| `MAX`、`MIN` | 最大、最小 | 跳过 |

::: notes
全部 48 种商品：最低价 3.50，最高价 99.00，平均价 23.33，总库存 3339。
:::

## GROUP BY：分组统计
!sim group-having
- 每个类别一个“篮子”
- 每个篮子变成**一行**
- SELECT 里只写**分组列和聚合函数**

## HAVING：筛选分组
| | WHERE | HAVING |
|---|---|---|
| 筛选对象 | 分组**前**的行 | 分组**后**的组 |
| 能用聚合函数吗 | 不能 | 能 |
| 比方 | 装篮子前挑掉 | 数完后拿走篮子 |

```sql
SELECT category_id, COUNT(*) AS 商品数
FROM product GROUP BY category_id
HAVING COUNT(*) >= 7;      -- 类别 1、6、8
```

# 4.6 书写顺序和执行顺序

## SELECT 的执行顺序
!sim sql-order
- FROM → WHERE → GROUP BY → HAVING
- → SELECT → ORDER BY → LIMIT
- WHERE 里**不能用别名**和聚合函数
- ORDER BY 里**可以用别名**

# 4.7 NULL 的坑

## NULL 的坑
| 表达式 | 结果 |
|---|---|
| `NULL = NULL` | NULL（不是真） |
| `NULL IS NULL` | 1 |
| `1 + NULL` | NULL |
| `AVG(5, 3, NULL, 4)` | 4，不是 3 |

::: notes
stars 列四行 5、3、NULL、4：COUNT(*) = 4，COUNT(stars) = 3，AVG = 4.0，SUM / COUNT(*) = 3.0。AVG 的分母不算 NULL。业务上 NULL 应当按 0 算时用 AVG(IFNULL(stars, 0))。
:::

## 前沿视窗：用大白话问数据
| 检查大模型写的 SQL | 常见错误 |
|---|---|
| 条件有没有括号 | AND、OR 混用 |
| 日期范围对不对 | BETWEEN 漏掉最后一天 |
| NULL 考虑了吗 | 散客被漏掉 |
| 统计口径对不对 | 退款订单算没算 |
| 行数合不合理 | 总数对得上吗 |
